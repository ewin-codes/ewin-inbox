EWIN Inbox: Telegram

Telegram Bot connector for EWIN Inbox. Receive and answer Telegram messages from the unified Odoo inbox, linked to Odoo contacts and mirrored into Discuss.

Odoo 18 LGPL-3 Tested

Highlights

  • Telegram Bot API over a secured webhook (per-account secret, checked on every request)
  • Two-way media — photos, documents, voice, video and stickers
  • Instant synchronous send with delivery status on each message
  • Automatic contact matching and creation as res.partner
  • Conversations mirrored into Odoo Discuss

Requirements

  • EWIN Inbox (ewin_omnichannel_core) installed
  • A Telegram bot token from @BotFather
  • A public HTTPS endpoint reachable by Telegram for the webhook
