EWIN Inbox: Viber

Viber bot connector for EWIN Inbox. Customers write to your Viber bot; operators answer from the Odoo inbox.

Odoo 18LGPL-3FreeNot yet verified live
Status: not yet verified live. This connector is implemented and covered by automated tests, but it has not yet been verified against a live provider account. Try it on a staging database before relying on it in production.

Highlights

  • Viber Bot API over a webhook
  • Two-way text and media
  • Customers matched to or created as Odoo contacts

Requirements

  • EWIN Inbox (ewin_omnichannel_core) installed
  • A Viber bot authentication token
  • A public HTTPS address Viber can reach for the webhook

Data and external services

Messages, files and the customer's Viber name travel between Odoo and the Viber Bot API (chatapi.viber.com). Nothing is sent anywhere else.
