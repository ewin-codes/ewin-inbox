EWIN Inbox: Live Chat

Brings Odoo's own website Live Chat into EWIN Inbox, so operators answer site visitors next to every other channel.

Odoo 18LGPL-3FreeTested on a live account

Highlights

  • Bridges Odoo's website_livechat into the inbox
  • Runs inside Odoo: no webhook and no public address needed
  • Two-way messaging with the visitor
  • Known contact, returning visitor or anonymous guest, each told apart

Requirements

  • EWIN Inbox (ewin_omnichannel_core) installed
  • Odoo Website Live Chat (website_livechat) installed and configured

Data and external services

Nothing leaves Odoo: the visitor's chat is already an Odoo record, and the connector works on it in place.
