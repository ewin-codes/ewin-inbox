EWIN Inbox: Messenger

Facebook Messenger (Pages) connector for EWIN Inbox. Receive and answer Messenger conversations for your Facebook Page from the unified Odoo inbox, linked to Odoo contacts and mirrored into Discuss.

Odoo 18 LGPL-3 Tested

Highlights

  • Facebook Messenger for Pages over the Meta Graph API
  • Two-way media messaging
  • Watermark-based delivery and read receipts
  • Contact enrichment via Graph profile lookup
  • 24-hour-window handling
  • Fail-closed webhook — HMAC signature verified over the raw body (App Secret)

Requirements

  • EWIN Inbox (ewin_omnichannel_core) installed
  • A Facebook Page and a Meta app with a Page access token and App Secret
  • A public HTTPS endpoint reachable by Meta for the webhook
