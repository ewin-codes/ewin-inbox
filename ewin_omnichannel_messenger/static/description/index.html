EWIN Inbox: Messenger

Facebook Messenger connector for EWIN Inbox. Conversations with your Facebook Page land in the Odoo inbox.

Odoo 18LGPL-3FreeTested on a live account

Highlights

  • Messenger for Pages over the Meta Graph API
  • Two-way media messaging
  • Delivery and read receipts
  • Customer name looked up from the profile
  • 24-hour window handled
  • Webhook that fails closed: the HMAC signature is checked over the raw body

Requirements

  • EWIN Inbox (ewin_omnichannel_core) installed
  • A Facebook Page and a Meta app with a Page access token and App Secret
  • A public HTTPS address Meta can reach for the webhook

Data and external services

Messages, files and the customer's public profile travel between Odoo and the Meta Graph API (graph.facebook.com). Nothing is sent anywhere else.
