EWIN Inbox: Instagram

Instagram Direct connector for EWIN Inbox, with Instagram business login and no Facebook Page required.

Odoo 18LGPL-3FreeNot yet verified live
Status: not yet verified live. This connector is implemented and covered by automated tests, but it has not yet been verified against a live provider account. Try it on a staging database before relying on it in production.

Highlights

  • Instagram Graph API with Instagram business login
  • Two-way media with delivery and read receipts
  • Story mentions and story replies arrive as conversations
  • Long-lived access token refreshed automatically
  • 24-hour window handled, with the optional Human Agent tag
  • Webhook that fails closed: the HMAC signature is checked over the raw body

Requirements

  • EWIN Inbox (ewin_omnichannel_core) installed
  • An Instagram professional account and a Meta app (App Secret)
  • A public HTTPS address Meta can reach for the webhook

Data and external services

Messages, files and the customer's Instagram username travel between Odoo and the Instagram Graph API (graph.instagram.com). Nothing is sent anywhere else.
