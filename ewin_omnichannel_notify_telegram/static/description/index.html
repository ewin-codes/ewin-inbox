EWIN Inbox: Alerts

Tells your team in Telegram the moment a customer writes to EWIN Inbox, on any channel, so nobody has to keep Odoo open.

Odoo 18LGPL-3Free

Highlights

  • Notifies the assigned operator personally, or the team chat while nobody is assigned
  • One notification per burst of messages, not one per message (10 minutes by default)
  • Each notification names the channel and the customer, previews the message and links back to the conversation
  • Operators connect their own Telegram from Preferences with a one-time link
  • A separate bot from the customer-facing Telegram connector, and no dependency on it

Requirements

  • EWIN Inbox (ewin_omnichannel_core) installed
  • A second Telegram bot token from @BotFather, distinct from any customer-facing bot
  • A public HTTPS address Telegram can reach for the webhook

Data and external services

Each notification sends the channel name, the customer's name and the first lines of their message to the Telegram Bot API (api.telegram.org), addressed to your own operators. Nothing is sent anywhere else.
